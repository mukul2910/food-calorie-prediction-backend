# Food Calorie Prediction Backend

## Project Overview
This project predicts the calorie value of food items using machine learning models.

## Dataset
Food Nutrition dataset containing:
- Grams
- Protein
- Fat
- Saturated Fat
- Fiber
- Carbs
- Category

## Models Used
1. Decision Tree Regressor
2. Neural Network (MLP Regressor)

## Evaluation Metrics
- MAE (Mean Absolute Error)
- R2 Score

## Result
Neural Network performed better with lower MAE and higher R2 score.

## Output
The trained model is saved as:
food_calorie_model.pkl
